# Teslo API

### 1. Clonar proyecto
### 2. Ejectar ```yarn install o yarn``` para reconstruir los modulos de node
### 3. Clonar el archivo ```.env.template``` y renombrarlo a ```.env```
### 4. Levantar la base de datos ```docker-compose up -d```
### 5. Ejecutar SEED ```http://localhost:3000/api/seed```
### 6. Levantar el proyecto en modo de produccción ```yarn start:dev```
